# Wordle Console Game 🎮

Консольная версия игры Wordle на Python.

Игроку нужно угадать случайное слово из 5 букв за ограниченное количество попыток.

---

# 🚀 Возможности

- Случайный выбор слова из файла
- Цветной вывод через Colorama
- ASCII-заголовок через PyFiglet
- Проверка правильных букв
- Ограничение по попыткам
- Возможность начать новую игру

---

# 🛠 Используемые библиотеки

- Python 3.12
- colorama
- pyfiglet
